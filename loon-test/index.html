Loon 自检面板

用途：快速触发各类请求，然后去 Loon 的请求/连接日志确认命中的策略。网页本身无法直接读取 Loon 内部策略组，所以“分流是否正确”以 Loon 日志为准。

这里只能验证当前这个网页请求走出的 IP/国家，不代表所有 App 都走同一策略。

2. 分流触发器

点一下即可触发请求。随后立刻打开 Loon 请求日志，搜索对应域名，看策略是否符合“期望”。

3. 广告/追踪拦截快速测试

下面会用 no-cors 请求几个常见广告/追踪域名。若被 Loon 在网络层拦截，通常会显示“被拦截/失败”。这只是快速筛查，不能替代具体 App 的开屏广告实测。

4. Apple Weather 检查方法

这个网页不能读取天气 App 内部 Script。正确验证方式是：打开苹果天气 → 回到 Loon 请求日志 → 搜索 weatherkit.apple.com。

至少应看到 /api/v1/availability/ 或 /api/v2/weather/ 请求，并且对应 Script 有执行记录。天气 App 本身还应正常显示天气数据。
